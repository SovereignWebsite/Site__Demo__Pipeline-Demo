Use this site with your AI

This site is written for people and for AI agents. Point your agent at llms.txt and tell it who you act for; it will find the right instructions.

If you are visiting

Paste this into any assistant that can read web pages:

Read https://pipeline-demo.sovereignweb.site/llms.txt and follow the instructions for a visitor.
Then answer my questions about this site, with a link for each point,
and say plainly when the site does not say something.

If you want something changed

This site has no owner yet; the team keeps it and Dinis Cruz decides. Ask for a change with an issue on the repository, or give your agent this:

Read https://pipeline-demo.sovereignweb.site/llms.txt, then draft an issue for
https://github.com/SovereignWebsite/Site__pipeline-demo
asking for this change: [describe the change].

For agents

  • llms.txt: what this site is and what to do, by who you act for.
  • data/agents.json: the agents that work on this site.
  • key.json: the public keys of the agent that keeps it, copied from the Factory's team/keys.json.
  • The repository: every file and every change.
